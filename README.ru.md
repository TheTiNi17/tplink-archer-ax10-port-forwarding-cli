# tplink-pf-manager

[English version](README.md)

Утилита командной строки для управления правилами проброса портов и UPnP
на роутерах TP-Link Archer.

Две формы:
- Python-скрипт (Python 3.9+)
- Готовый `.exe` (Windows)

## Проблема

В веб-интерфейсе TP-Link нет пакетного переключения правил проброса портов.
При большом количестве правил (игры, серверы, сервисы) включать и выключать
их по одному неудобно. UPnP-правила создаются автоматически, посмотреть
и отключить их быстро нельзя.

## Решение
## Проверено на TP-Link Archer AX10 v1.0

Обращается напрямую к внутреннему API роутера:

- Включение / выключение / инверсия групп правил проброса по префиксу имени.
- Управление UPnP (вкл / выкл / статус / инверсия).
- Список активных UPnP-пробросов.

Работает с любыми именами правил.

## Команды

| Команда | Описание |
| `pf-tool portrules status [префикс]`                | Список правил (опциональный фильтр) |
| `pf-tool portrules on` / `off` / `toggle [префикс]` | Управление подходящими правилами |
| `pf-tool upnp status`                               | Состояние UPnP |
| `pf-tool upnp on` / `off` / `toggle`                | Управление UPnP |
| `pf-tool upnp list`                                 | Активные UPnP-пробросы |

Если `префикс` не указан — команда применяется ко всем правилам.

## Установка

### Вариант 1 — Windows `.exe`

1. Скачать `pf-tool.exe` из [Releases](../../releases).
2. Создать `.env` рядом:

ROUTER_IP=192.168.0.1
ROUTER_USERNAME=admin
ROUTER_PASSWORD=ваш_пароль_от_роутера

3. Запустить:
pf-tool.exe portrules status (пример)

### Вариант 2 — Python-скрипт

1. Требования: Python 3.9+, `requests`, `urllib3`, `pycryptodome`.

2. Запуск:
python pf.py portrules status

## Примечания
Роутер допускает только одну административную сессию. Перед запуском закройте веб-интерфейс.
.env должен лежать рядом со скриптом или .exe.
Перед изменением правило читается с роутера; посторонние поля не перезаписываются.
